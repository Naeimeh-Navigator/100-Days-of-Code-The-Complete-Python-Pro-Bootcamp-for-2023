# Day 21 – Snake Game (Part 2) 🐍

This folder contains **Day 21** of  
**100 Days of Code: The Complete Python Pro Bootcamp (Udemy)**.

This day was about finishing the Snake game by adding the parts that actually make it feel like a real game: food, scoring, and game-over logic. Compared to Day 20, this part felt more rewarding because everything finally comes together.

## What was added (Day 21)

- Used **class inheritance** to organize the code better
- Detected collisions between the snake and the food
- Generated new food at random locations
- Added a **scoreboard** and kept track of the score
- Detected collisions with the wall
- Detected collisions with the snake’s own tail
- Practiced slicing lists and tuples to manage snake segments

By the end of this day, the game is fully playable and behaves the way the classic Snake game should.
