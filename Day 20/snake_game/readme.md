# Day 20 – Snake Game (Part 1) 🐍

This folder contains **Day 20** of  
**100 Days of Code: The Complete Python Pro Bootcamp (Udemy)**.

On this day, the goal was to start building the classic **Snake game** using
Python, Object-Oriented Programming, and the `turtle` module.

The snake game was one of my first mobile gaming experiences (Nokia 3310 era),
so recreating it in Python was both nostalgic and a great OOP exercise. I was also trying to keep a consistent coding routine during the very last days of **2025**

## What was implemented (Day 20)

- Created the snake body using multiple square segments
- Implemented continuous forward movement
- Enabled keyboard controls:
  - Up
  - Down
  - Left
  - Right
- Structured the code using classes and multiple files

This part focuses on movement and control logic only.  
Game features like food, scoring, and collisions are added in **Day 21**.
